About MultiModal AI System

MultiModal AI System is an intelligent web application that combines Natural Language Processing and Computer Vision into a single platform. Users can classify multiple email messages for spam detection and perform object detection on multiple images using a clean and interactive dashboard.

Current Features

  • Batch Email Spam Detection (Up to 10 Emails)
  • Batch Image Object Detection (Up to 10 Images)
  • YOLOv8 based Real-Time Object Detection
  • Interactive Dashboard UI
  • Responsive Web Interface using Flask
